# Fan Dipole Project

## Goal
Design and build a multiband HF fan dipole antenna capable of long-distance communication with South America from Georgia, USA.

## Bands
- 10m
- 15m
- 20m

## Current Status
Research Phase

## Why This Project?
This project is part of my RF engineering learning journey and will document:
- antenna theory
- propagation
- RF testing
- SWR tuning
- real-world DX communication
